Workspace Cicados

Dans le cadre de ma formation au titre de Développeur Web et Web Mobile (DWWM), j'ai développé en autonomie Workspace Cicados, une plateforme web modulaire destinée aux passionnés de jeux de société et d'événements TCG (Trading Card Games). L'objectif principal est de permettre la réservation de tables de jeu avec un algorithme anti-surbooking, la gestion des tournois et l'intégration dynamique du catalogue BoardGameGeek (BGG).

Le projet repose sur une architecture conteneurisée avec Docker, orchestrée par Docker Compose, sécurisée via JWT et RBAC (Role-Based Access Control), et routée dynamiquement par un Reverse Proxy Nginx Alpine.

L'infrastructure intègre une API REST Express sous Node.js avec persistance des données sous MySQL 8.0, ainsi qu'un mécanisme de basculement dynamique de secours (Failover) vers un stockage JSON local pour garantir la haute disponibilité du catalogue en cas d'indisponibilité de la base de données.

Les composants techniques sont répartis comme suit :
Microservice / Composant Rôle principal Technologie Base de données
frontend Interface utilisateur SPA réactive & catalogue React 18 / Vite 7 / Tailwind -
backend-api API REST, logique métier & contrôleurs Node.js / Express MySQL 8.0
auth-service Authentification JWT & Sécurité RBAC Express / Bcrypt / JWT MySQL (users)
reservation-service Détection d'overlap & allocation dynamique Express / Algorithme SQL MySQL (reservations)
bgg-proxy-service Relais API BGG & conversion XML2 vers JSON Fast-XML-Parser / Express API BGG / Cache
failover-service Sauvegarde de secours en cas de panne BDD Express / fs.readFile boardgame-list.json
nginx-gateway API Gateway, Edge routing, SSL & gzip Nginx Alpine -
database Stockage relationnel & intégrité des données MySQL 8.0 Volume mysql_data
Fonctionnalités actuellement disponibles :
  • Réservation de tables de jeu en temps réel avec algorithme anti-surbooking
  • Inscription et désinscription réactive aux tournois TCG et événements
  • Messagerie support multi-tours bidirectionnelle (Membre <-> Admin) avec notifications réactives
  • Importation et conversion automatisée du catalogue BoardGameGeek (XML2 vers JSON)
  • Dashboard Administrateur complet (Gestion CRUD des jeux, événements et messages)
  • Basculement automatique de secours (Failover SQL vers JSON)

Une campagne de tests automatisés E2E (Puppeteer) et de tests d'intégration backend a été réalisée sur le service de réservation, avec une validation complète des parcours utilisateurs critiques.
